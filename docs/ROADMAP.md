# Agent Capsule Roadmap

This is the public roadmap for the current Agent Capsule direction.

## Near Term

- Make `pip install agentcapsule` the default trial path.
- Keep the README focused on first-10-seconds clarity and quick adoption.
- Lean into A2A handoffs and reference-mode payload delivery.
- Improve trust primitives and policy clarity for real-world handoffs.
- Publish the community surface: contributing guidance, issue templates,
  roadmap, and release notes.

## Next

- Improve scan output and governance ergonomics for operator workflows.
- Expand docs for agent-to-agent, chat, ticket, and email handoff patterns.
- Add more examples for verified payload delivery in structured channels.
- Tighten the release process around versioning, PyPI, and changelog hygiene.

## Later

- Broader integrations for multi-agent workflows and external orchestration
  surfaces.
- Optional policy and trust extensions for production deployment patterns.
- Dashboard and registry ideas once the core protocol path is stable.
- Tiny JS/TS reference implementation for `pack` and `verify` to support
  browser-based agents, frontend tools, and cross-language test vectors.
