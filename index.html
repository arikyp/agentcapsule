Agent Capsule Protocol

Verifiable, text-native artifact handoffs between agents. Pack, send, verify, and ingest safely across chat threads, A2A messages, and workflow frameworks.

GitHub Repository PyPI Package Receiver Guide

Function

Protect machine-readable handoffs from truncation, mutation, and ambiguity by wrapping payloads in a deterministic capsule format.

Value

Receiver-side safety by default: policy checks, hash verification, optional signature trust, then sandboxed unpack.

Integration

One command and one SDK call for adoption: agentcapsule ingest ... and ingest_messages(...).

# 60-second quickstart
python3 -m pip install agentcapsule
agentcapsule pack payload.json --out capsule.txt
agentcapsule verify capsule.txt
agentcapsule unpack capsule.txt --out decoded
For framework usage (LangGraph, CrewAI, LlamaIndex patterns), see docs/INTEGRATIONS.md.
